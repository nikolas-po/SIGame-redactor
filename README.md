# СиПак — редактор пакетов SIGame

Создание и правка наборов вопросов (`.siq`) для «Своей игры».

**Слоган:** Собери пакет. Запусти игру.

## Запуск

```bash
python main.py
```

Windows: `py main.py`. Нужен Python 3 + tkinter.

## Сборка одного exe

Дважды `build.bat` (Windows) или `./build.sh` (Linux/macOS).  
Результат: `dist/SiPak.exe` (или `SiPak`).

## Как выглядит окно

```
┌─ СиПак ──────────────────────────────── Играть | Подсказки | QR ─┐
│ [Как начать?] [Предпросмотр] [Справка] [Обновления] [Открыть]…   │
├──────────────────┬───────────────────────────────────────────────┤
│ Структура пакета │  Свойства / вопрос                            │
│ ▼ Пакет          │  Тип: ○ обычный ○ аукцион ○ кот ○ без риска │
│   ▼ Раунд 1      │  Модификаторы: □ близкий ответ □ без штрафа   │
│     ▼ Тема       │  Варианты: Текст | Аудио  [+ Вариант]         │
│       • 100      │  Содержимое: текст / фото / звук / видео      │
│       • 200 ×2   │  Ответы · комментарий · [Предпросмотр]        │
│   ▼ Финал        │  [Применить изменения]                        │
├──────────────────┴───────────────────────────────────────────────┤
│ Статус: сохранено / * не сохранено                               │
└──────────────────────────────────────────────────────────────────┘
```

Слева — дерево. Справа — форма выбранного элемента.  
Сверху — действия. Справа сверху — игра и QR.

## Кратко по работе

1. **+ Раунд** → **+ Тема** → **+ Вопрос**
2. Тип, текст/медиа, ответы → **Применить** → **Сохранить** (.siq)
3. **Играть на сайте** → загрузить пакет на SIGame Online
4. **QR комнаты** — ссылка для входа игроков
5. При запуске (если задан `UPDATE_GITHUB_REPO`) — проверка обновления exe

Сайт: https://sigame.vladimirkhil.com/

## Обновления

См. `UPDATES.md`. В `constants.py` укажите `UPDATE_GITHUB_REPO = "user/repo"`.

## Пакет-пример

Рядом с архивом: `Экономика_мемы_кино_новости.siq` — экономика, мемы, кино, все механики.
